# 📚 ReadCloud — Sistema de Biblioteca em Nuvem PT/BR

O **ReadCloud** é um sistema de gerenciamento de biblioteca desenvolvido em Java com integração a banco de dados SQL local e cloud.  
O projeto foi criado como trabalho acadêmico com foco em arquitetura, organização de dados e aplicação prática de desenvolvimento back-end.

A proposta é simular um sistema real de biblioteca digital, permitindo organização e gerenciamento de livros de forma eficiente e escalável.

---

## 🚀 Sobre o projeto
O ReadCloud foi desenvolvido com o objetivo de aplicar conceitos reais de desenvolvimento de software, desde modelagem de banco até integração com nuvem.

A aplicação permite o gerenciamento de um acervo de livros, utilizando banco de dados local e também hospedagem em nuvem para simular um ambiente profissional de produção.

Além da construção técnica, o projeto teve foco em boas práticas de código, organização e versionamento.

---

## 🛠️ Tecnologias utilizadas
- Java  
- SQL (banco de dados relacional)  
- JDBC  
- Azure SQL Database  
- Git & GitHub  

Banco de dados hospedado localmente e também em nuvem através da plataforma da Microsoft para simulação de ambiente real.

# 📚 ReadCloud — Cloud Library Management System EN/US

**ReadCloud** is a library management system developed in Java with integration to both local SQL databases and cloud infrastructure.  
This project was created as a college assignment with a focus on architecture, data organization, and practical back-end development.

The proposal is to simulate a real digital library system, allowing efficient and scalable organization and management of books.

---

## 🚀 About the project
ReadCloud was developed with the goal of applying real-world software development concepts, from database modeling to cloud integration.

The application enables the management of a book collection using a local database and a cloud-hosted database to simulate a professional production environment.

Beyond the technical implementation, the project also focused on clean code practices, organization, and version control.

---

## 🛠️ Technologies used
- Java  
- SQL (Relational Database)  
- JDBC  
- Azure SQL Database  
- Git & GitHub  

The database is hosted locally and also in the cloud through the :contentReference[oaicite:0]{index=0} Azure platform to simulate a real-world environment.
